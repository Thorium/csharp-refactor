# Changelog

The analyzers package, the `csharp-refactor` tool and both editor extensions share one version. The NuGet packages carry the notes of the last six versions; this file keeps every one.

## 0.1.0

First version. The property suite reaches 121 of the 124 rules and tries every fix under the conventions of real files (regions, directives and comments inside members, CRLF, tabs, pragmas) and at every language version from C# 7.3 up; the example suite tries the conditions any rule may meet (shadowing, reflection and `nameof`, expression trees, `dynamic`, `unsafe`, partial types across files, interface and override members, generated files, a framework lacking a type). What that found before the release: CR0084 offered `readonly` where a method wrote the field; CR0109 hoisted a pattern the engine rejects into a generated regex; CR0047 spelled `System.Threading.Lock` and `new()` into files below C# 13 and C# 9; CR0009 folded an `or` pattern below C# 9 and stacked labels with a bare LF in a CRLF file; CR0029 fused Selects inside an expression tree; CR0153 missed a partial type's other file and a field reached by reflection; the tool rewrote files carrying an `<auto-generated>` header. The MCP server (`--mcp`) is now under test end to end.
